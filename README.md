# My Workout Tracker

My Workout Tracker is a full-stack web application that allows users to create an account, log in, and track their workout progress. The project includes a sign-up system, secure password handling, and user login functionality. Once logged in, users can access pages for workout tracking, social interaction, and general app navigation.

## Features

- User sign-up and login system
- Secure password handling for account creation
- Home page for navigating the application
- Workout spreadsheet page for logging lifts
- Ability to enter the lift name, weight, sets, and reps
- Automatic date entry when a workout is logged
- Social page currently in development

## Tech Stack

- HTML
- CSS
- JavaScript
- React
- MongoDB Atlas
- Render

## Project Overview

The main purpose of this project is to help users track their workouts in a simple and organized way. After logging in, users can enter specific lifts into a spreadsheet-style page, including the weight used, number of sets, and number of reps. The app automatically adds the date, making it easier for users to review their training history over time.

This project also includes a social page where users will eventually be able to interact with others. I am currently working on improving the social page and making the workout entry process faster and easier to use. I am also continuing to refine the layout and user experience so the app feels more practical and polished.
